# AI Inventory Audit Checklist

## Inventory Completeness

- [ ] All known AI systems recorded
- [ ] Department survey completed
- [ ] Vendor AI tools identified
- [ ] Shadow AI tools documented
- [ ] Retired tools marked

## Ownership

- [ ] Business owner assigned
- [ ] System owner assigned
- [ ] Data owner assigned where needed
- [ ] Governance owner identified for high-risk systems

## Risk and Classification

- [ ] Data classification completed
- [ ] Risk tier assigned
- [ ] Public-facing systems flagged
- [ ] Restricted-data systems flagged
- [ ] Human review requirement documented

## Approval

- [ ] Approval status recorded
- [ ] Required controls documented
- [ ] Review date assigned
- [ ] Governance decision retained

## Monitoring

- [ ] Dashboard maintained
- [ ] High-risk systems reviewed
- [ ] Shadow AI remediation tracked
- [ ] Inventory changes logged
- [ ] Audit evidence retained
